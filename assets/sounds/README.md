# Вспоминайка — звуки

Оригинальные синтетические звуки для проекта.

- garden.wav — тихий сад: ветер и птицы, 20 секунд, можно зацикливать
- click.wav — мягкий щелчок выбора
- correct.wav — спокойный положительный сигнал
- try-again.wav — нейтральный сигнал повторной попытки
- page.wav — перелистывание/переход
- cash-register.wav — короткий звон старого кассового аппарата

Рекомендуемая громкость в коде:
garden 0.15–0.20
click 0.15–0.25
correct 0.25–0.35
try-again 0.20–0.30
page 0.20–0.30
cash-register 0.25–0.35
